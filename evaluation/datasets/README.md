# Datasets

Due to access restrictions and environment limits, the full datasets (payloadbox, XSSShield, Common Crawl) are not downloaded entirely. Instead, a mock subset of `xss_payloads.txt` and `benign_strings.txt` have been generated for testing and validation purposes.

The actual datasets required for a production evaluation:
1. **payloadbox/xss-payload-list**: https://github.com/payloadbox/xss-payload-list
2. **XSSShield dataset**: IEEE DataPort (DOI: 10.21227/...)
3. **Benign URL corpus**: Common Crawl (100k sample)
